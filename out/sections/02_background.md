## Background

The evolution of large language models (LLMs) from static sequence transduction to dynamic, agentic systems is rooted in the foundational shift toward self-attention. The Transformer architecture, as introduced by [Vaswani et al., 2017], revolutionized sequence modeling by replacing recurrence and convolution with a multi-head self-attention mechanism. This design allows for the computation of global dependencies across sequences, defined by the attention function: $\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$. By projecting queries, keys, and values into $h$ different representation subspaces through multi-head attention, the model can jointly attend to information from disparate positions. This architecture achieved state-of-the-art performance on the WMT 2014 English-to-German translation task with 28.4 BLEU, demonstrating a superior capacity for parallelization compared to RNN-based models. However, the Transformer’s primary limitation remains its reliance on static, feed-forward computation, which lacks the inherent mechanisms for long-term memory management or logical reasoning grounding.

To address the limitations of static transduction, research has shifted toward eliciting reasoning capabilities through prompting strategies. [Wei et al., 2022] demonstrated that augmenting few-shot exemplars with intermediate natural language reasoning steps—a technique termed "Chain-of-Thought" (CoT) prompting—significantly enhances the performance of LLMs on complex tasks. By decomposing multi-step problems into manageable logical increments, CoT prompting enabled the PaLM 540B model to achieve 56.9% accuracy on the GSM8K benchmark, a substantial improvement over standard few-shot prompting (17.9%). The authors identified that CoT reasoning is an emergent ability of model scale, becoming effective only in models with approximately 100B parameters or more. Despite these gains, CoT remains an ungrounded process; models can generate coherent reasoning traces that lead to incorrect conclusions, as the internal logic is not verified against external constraints or factual databases.

The ReAct paradigm, proposed by [Yao et al., 2023], addresses the separation between reasoning and acting by interleaving internal thought processes with external tool interactions. In the ReAct framework, the model generates a "thought" trace to guide its decision-making, followed by an "action" that interfaces with an external environment or API. This synergy allows the model to ground its reasoning in real-world observations. For instance, in the ALFWorld decision-making environment, ReAct achieved a 71% success rate, significantly outperforming act-only baselines (45%). By treating language as a medium for both planning and environmental interaction, ReAct mitigates hallucination and improves the interpretability of model decisions. Nevertheless, ReAct is primarily a prompting-based framework, which can lead to repetitive loops if the model fails to retrieve informative search results, and it does not inherently learn to optimize its interaction strategy over time.

Complementary to ReAct, [Schick et al., 2023] introduced Toolformer, which focuses on the self-supervised acquisition of tool-use capabilities. Unlike prompting-based approaches, Toolformer is finetuned to autonomously decide when and how to invoke external tools, such as a calculator or a search engine, based on the potential for perplexity reduction. By sampling potential API calls and filtering them based on their impact on language modeling loss, the model learns to integrate tools into its generation process without extensive human supervision. Toolformer demonstrated that tool use is a learnable skill, achieving 40.4% accuracy on the ASDiv math benchmark, compared to 14.0% for GPT-3. However, the current implementation of Toolformer is constrained by its inability to perform chained tool interactions, where the output of one API call serves as the input for a subsequent one. 

Finally, recent advancements in generative agents, such as those described by [Park et al., 2023], have integrated memory streams and reflection mechanisms to maintain long-term social coherence. These agents utilize a memory stream to store past experiences, which are then processed via reflection to synthesize higher-level insights. While these architectures achieve a TrueSkill rating of 29.89 in simulated social environments, they impose significant computational costs due to the frequency of reflection cycles and the management of large-scale memory buffers. The current landscape of LLM research thus reveals a tension: while CoT [Wei et al., 2022] provides logic, ReAct [Yao et al., 2023] provides grounding, and Toolformer [Schick et al., 2023] provides autonomous tool discovery, there remains a critical need for a unified architecture that can recursively chain these capabilities while maintaining memory-augmented efficiency. The proposed RCTA framework seeks to resolve these tensions by synthesizing these disparate mechanisms into a single, self-evolving cognitive loop.
