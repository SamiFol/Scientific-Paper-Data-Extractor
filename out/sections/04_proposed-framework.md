## Proposed Framework

The Unified Agentic Transformer (UAT) architecture is designed to overcome the limitations of modular, prompt-dependent agentic systems by embedding the reasoning-acting-memory loop directly into the model’s latent space. By transitioning from the static sequence transduction paradigm established in [Vaswani et al., 2017] to a dynamic, iterative processing framework, UAT facilitates a seamless flow of information between internal reasoning traces and external tool execution. This section details the three pillars of the UAT architecture: the persistent hierarchical memory stream, the recursive planning mechanism, and the self-supervised tool-chaining algorithm.

### Memory Stream Integration

Unlike the memory architectures proposed in [Park et al., 2023], which rely on periodic, high-cost reflection cycles, UAT implements a persistent, hierarchical memory stream that operates as an auxiliary latent buffer. This buffer is structured into three distinct tiers: the *Episodic Buffer* (short-term, high-fidelity traces of recent tokens), the *Semantic Cache* (mid-term, compressed representations of reasoning steps), and the *Long-term Knowledge Base* (persistent, distilled insights).

The integration mechanism utilizes a cross-attention gating function that allows the Transformer to query the memory stream at any point in the generation process. Given a hidden state $h_t$ at time $t$, the model computes a retrieval query $q_t = W_q h_t$. The memory retrieval score is determined by a weighted combination of recency, importance, and relevance, following the scoring function $S(m) = \alpha_r \cdot \text{recency}(m) + \alpha_i \cdot \text{importance}(m) + \alpha_l \cdot \text{relevance}(q_t, m)$, where $\alpha$ hyperparameters are learned during the finetuning process. By storing intermediate tool outputs—a capability absent in the static tool-use paradigms of [Schick et al., 2023]—the model can retrieve the result of a previous calculation or search query to inform subsequent reasoning steps. This effectively transforms the memory stream into a dynamic workspace where information is not merely stored but actively refined through the model's internal reasoning engine.

### Hierarchical Planning

To address the failure modes associated with the separation of reasoning and acting observed in [Yao et al., 2023], UAT employs a hierarchical planning module. This module decomposes complex, high-level objectives into a sequence of sub-tasks, represented as latent tokens within the model's autoregressive stream. The planning process follows a recursive decomposition strategy: a top-level goal (e.g., "Solve the multi-hop arithmetic problem") is broken down into intermediate reasoning steps, which are then mapped to specific tool-invocation tokens.

The hierarchy is enforced by a constrained decoding mechanism that prevents the model from generating terminal responses until the planning tokens have been satisfied by external tool feedback. This structure ensures that the model maintains long-term coherence, as the high-level plan acts as a persistent constraint on the local reasoning steps. The planning module is trained using a self-supervised objective that minimizes the cross-entropy loss not only on the final answer but also on the successful completion of the decomposed sub-tasks. By leveraging the CoT-style reasoning traces introduced in [Wei et al., 2022], UAT ensures that each step of the plan is grounded in the current state of the memory stream, thereby reducing the likelihood of hallucinated reasoning paths.

### Tool-Chaining Algorithm

The core innovation of UAT is the self-supervised tool-chaining algorithm, which enables the model to utilize the output of one tool as the input for another. While [Schick et al., 2023] demonstrated that models can learn to call tools autonomously, their framework suffered from an inability to chain these calls, limiting performance on complex tasks like HotpotQA. UAT resolves this by introducing a special `<CHAIN>` token that signals the model to pause generation, execute the tool, and append the output to the memory stream before resuming the reasoning process.

The algorithm proceeds in three phases:
1. **Selection and Invocation:** The model predicts a tool-call token based on the current context and the retrieved memory state.
2. **Execution and Storage:** The external tool is executed, and the raw output is passed through a lightweight encoder to generate a latent representation, which is then written to the memory stream.
3. **Recursive Reasoning:** The model retrieves the updated memory state, which now contains the tool output, and generates the next reasoning trace.

This process is iterative. If the tool output is insufficient, the model is trained to generate a subsequent tool call, effectively creating a chain of dependencies. The training data for this mechanism is generated by bootstrapping from existing CoT traces, where tool calls are inserted at critical junctures. We employ a filtering mechanism based on perplexity reduction, similar to [Schick et al., 2023], to ensure that only tool calls that significantly improve the model’s predictive accuracy are retained in the training set. By finetuning on this augmented dataset, UAT learns to treat the tool-chaining process as a unified latent sequence rather than a series of disjointed prompts.

### Computational Efficiency and Latent Optimization

A significant challenge identified in [Park et al., 2023] is the high computational cost of maintaining and reflecting upon large memory buffers. UAT mitigates this by replacing the explicit, token-heavy reflection mechanism with a latent reflection process. Instead of generating natural language summaries of experiences, the model updates a compressed vector representation of the memory stream using a gated recurrent unit (GRU) integrated into the Transformer layers. This allows the model to maintain a "summary" of its history without the token-usage overhead of full-text reflection.

Furthermore, the integration of memory retrieval into the attention mechanism—rather than treating it as a separate, external lookup—reduces the latency of the agentic loop. By sharing parameters between the reasoning and retrieval heads, UAT achieves a more compact architecture that is better suited for real-time interactive environments. The efficiency gains are further supported by the use of a hierarchical memory structure, where only the most relevant segments of the memory stream are loaded into the attention window, thereby minimizing the computational burden of processing long-term context.

In summary, the UAT framework synthesizes the foundational Transformer architecture [Vaswani et al., 2017] with the agentic capabilities required for complex, multi-step reasoning. By unifying memory, planning, and tool-use into a single, finetuned latent process, UAT provides a robust solution to the limitations of current prompt-based agentic architectures. This approach not only enables autonomous tool-chaining but also provides a path toward memory-efficient, long-term reasoning in large language models. The subsequent evaluation plan will rigorously test these claims across a suite of arithmetic, retrieval, and decision-making tasks, comparing UAT against the established baselines of [Wei et al., 2022], [Yao et al., 2023], and [Schick et al., 2023].
