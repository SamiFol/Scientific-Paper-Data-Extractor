## Related Work: Prompting and Tool Use

The limitation of static reasoning traces, which are inherently ungrounded, has catalyzed the development of paradigms that bridge the gap between internal cognitive simulation and external environmental interaction. A pivotal advancement in this domain is the ReAct framework [Yao et al., 2023], which addresses the "black box" nature of Chain-of-Thought (CoT) by interleaving reasoning traces with task-specific actions. By augmenting the model's action space $A$ to include a language space $L$—where $a_t \in A$ represents an action and $\hat{a}_t \in L$ represents a "thought"—ReAct enables models to decompose complex goals into sub-tasks that are verified through external observation. For instance, in knowledge-intensive tasks like HotpotQA, the model generates thoughts to track progress and extract information, while simultaneously querying a Wikipedia API to ground its assertions. Empirical results underscore the efficacy of this synergy: on the ALFWorld benchmark, ReAct achieved a 71% success rate, significantly outperforming the 45% success rate of an "Act-only" baseline [Yao et al., 2023]. Crucially, this interleaved approach mitigates the error propagation and hallucination prevalent in purely internal reasoning, as evidenced by the reduction of hallucination rates to 0% in specific HotpotQA test cases compared to 56% for standard CoT [Yao et al., 2023].

While ReAct relies on few-shot prompting to elicit tool-use behavior, the Toolformer architecture [Schick et al., 2023] shifts this paradigm toward self-supervised learning. Toolformer addresses the challenge of making models capable of using external tools—such as calculators, Q&A systems, and search engines—without requiring extensive human-labeled demonstrations. The method involves three distinct phases: sampling potential API calls using in-context learning, executing these calls to obtain results, and filtering them based on their impact on the model's future token prediction loss. Specifically, a call is retained only if it reduces the cross-entropy loss by a threshold $\tau_f$ compared to the model's performance without the tool [Schick et al., 2023]. This approach demonstrates that tool use is a learnable skill that can be acquired autonomously. The performance gains are substantial; on the ASDiv math benchmark, Toolformer achieved 40.4% accuracy, compared to the 14.0% achieved by a GPT-3 baseline [Schick et al., 2023]. By integrating these tools, the model compensates for its inability to perform precise arithmetic or access real-time information, effectively extending its functional capabilities beyond the static constraints of its training data.

Despite these advancements, the "grounding problem" persists in both ReAct and Toolformer, albeit in different manifestations. In ReAct, the model remains susceptible to non-informative search results or repetitive loops, where it may generate redundant thoughts and actions without making progress toward the final goal [Yao et al., 2023]. Conversely, Toolformer, while robust in its self-supervised acquisition of tools, is fundamentally limited by its inability to perform chained or recursive tool use—the output of one tool cannot be dynamically fed as the input for a subsequent tool call [Schick et al., 2023]. Furthermore, both architectures primarily operate in a reactive, task-specific mode. ReAct’s reasoning is ephemeral, existing only within the context of the current prompt, and Toolformer’s tool-use is triggered by local perplexity reduction rather than a long-term strategic plan [Schick et al., 2023; Yao et al., 2023].

The tension between internal knowledge and external grounding is further highlighted by the failure modes observed in these systems. While CoT relies entirely on internal weights, which are prone to logical gaps, ReAct and Toolformer are vulnerable to the quality and relevance of the external tools provided. If a search engine returns irrelevant data or a calculator is invoked in an inappropriate context, the model’s reasoning trace can be derailed [Yao et al., 2023]. Moreover, the emergence of these capabilities is highly dependent on scale; both ReAct and Toolformer demonstrate that effective tool use and reasoning become viable only in models exceeding approximately 100B parameters [Wei et al., 2022; Yao et al., 2023; Schick et al., 2023]. This creates a barrier to entry for smaller, more efficient models. The current landscape suggests that while we have successfully moved from static transduction to reactive agents, the next critical evolution requires persistent memory architectures that can synthesize past tool-use experiences into high-level, long-term strategies, thereby addressing the current limitations in recursive tool chaining and computational efficiency.
