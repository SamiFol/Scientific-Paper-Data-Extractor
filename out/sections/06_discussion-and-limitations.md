## Discussion and Limitations

The experimental results validate the core thesis that the NeuroSymbolic-ReAct Agent (NSRA) architecture bridges the gap between static reasoning and interactive tool-augmented agents. By integrating a Chained Dependency Graph and hierarchical memory, NSRA achieves a performance profile that challenges the prevailing assumption that high-fidelity reasoning requires models exceeding 100B parameters [Wei et al., 2022]. Our 13B NSRA model demonstrates that by offloading logical verification and long-term state management to symbolic modules, we can mitigate the inherent limitations of standard Chain-of-Thought (CoT) prompting, specifically the susceptibility to error propagation and hallucination [Yao et al., 2023].

A central finding of this work concerns the tension between model scale and autonomous tool utility. While [Schick et al., 2023] established that models as small as 6.7B can learn basic API usage via self-supervised perplexity filtering, our results indicate that such models often fail in multi-step, long-horizon tasks due to an inability to maintain coherence across tool sequences. NSRA addresses this by anchoring the agent in a persistent memory stream, a mechanism adapted from [Park et al., 2023]. The performance delta observed in our ablations—where NSRA-A2 (isolated tools) consistently underperforms the full architecture—confirms that the ability to chain API calls is not merely an additive feature, but a prerequisite for solving complex, multi-hop tasks like those found in HotpotQA or ALFWorld. The reduction in repetitive search loops, which [Yao et al., 2023] identified as a primary failure mode in ReAct, suggests that our symbolic verification layer acts as a crucial guardrail against the "black box" nature of autoregressive generation.

Despite these advancements, several limitations persist. The computational overhead associated with maintaining the Chained Dependency Graph and the periodic synthesis of reflections remains non-trivial. While we demonstrate that NSRA reduces the need for massive model parameters, the inference-time cost of managing the memory stream and executing multi-step API calls introduces latency that may hinder real-time applications. Furthermore, the reliance on perplexity-based filtering for tool selection, while effective for reducing human supervision [Schick et al., 2023], remains sensitive to prompt phrasing. We observed instances where the model failed to trigger an API call despite the presence of a solvable mathematical problem, suggesting that the "self-teaching" mechanism is still prone to false negatives.

Additionally, the architecture is currently constrained by the scope of the pre-defined API set. While the Chained Dependency Graph allows for sophisticated logic, it does not yet support the dynamic discovery of new tools or the autonomous creation of complex APIs without prior definition.
